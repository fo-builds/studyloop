# StudyLoop

A clean focus timer, task board and streak tracker for students. Single-file web app — no build step, no accounts, works offline, all data stays in the browser.

## Features
- Pomodoro-style focus/break loops with auto-switching
- Task board with filters, persistence via localStorage
- Daily stats: loops, focus minutes, day streak
- Adjustable loop lengths, keyboard shortcuts (space = start/pause, r = reset)
- Dark, responsive UI
